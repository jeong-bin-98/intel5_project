# 🧠 릴레이 소켓 3D 탐지 및 빈픽킹 코어 (Detection & 3D Vision Core)

본 ディ렉토리(`src/detection/`)는 로봇 시스템의 궁극적인 두뇌 역할을 수행합니다. 단순한 2D 객체 인식을 넘어, 현실 세계의 3D 물리 법칙과 기하학(Geometry)을 아우르며, **"물체의 픽셀 좌표를 실제 로봇이 이동할 수 있는 공간 좌표(mm)로 변환하는 기적"**을 만들어내는 모든 핵심 로직이 집약되어 있습니다.

이 문서는 시스템을 유지보수하거나 업그레이드할 로봇 비전 엔지니어 및 연구자들을 위해, 각 모듈 내부의 수학적/공학적 작동 원리를 바닥부터 끝까지 깊이 있게 해부해 놓은 **심층 설계 및 원리 명세서(Architecture & Mechanics)**입니다.

---

## 🏛️ 코어 모듈 심층 해부 (Module Deep Dive)

### 1. `binpicking_3d.py` (메인 오케스트레이터 & 동기화 제어)
모든 센서 데이터(카메라)와 AI 추론(YOLO), 그리고 물리적 액추에이터(로봇 팔)를 하나의 시간 축에서 동기화하며 통제하는 메인 루프입니다.

*   **멀티 프레임 안정화 기법 (Multi-Frame Median Capture)**:
    일반적인 실시간 스트리밍에서는 카메라 노이즈가 끊임없이 발생합니다. 하지만 로봇이 픽킹을 시도할 때(`--pick` 모드)는 오차 1mm가 충돌 사고로 직결됩니다. 이를 방지하기 위해 로봇이 이동하기 직전, **순간적으로 10장의 깊이(Depth) 프레임을 연속 촬영한 뒤 중앙값(Median)을 추출하는 공간적/시간적 스무딩 결합 기법**을 사용합니다. 이로 인해 돌발적인 노이즈 픽셀(Spike)이 완전히 소거된 극도로 깔끔한 정지 3D 뎁스 맵을 RANSAC 알고리즘에 넘길 수 있습니다.
*   **에러 핸들링 및 예외 처리**:
    물체를 찾지 못했을 때의 로직, 깊이 값이 `0`(센서 반사 오류)으로 떨어졌을 때의 Fallback(우회) 로직 등 현장에서 발생할 수 있는 결측치(Missing Data) 방어 코드가 설계되어 있습니다.

### 2. `geometry.py` (3D 공간 수학 및 추론 알고리즘)
공간 지각과 수학적 계산을 100% 담당하는 모듈로, 삼각함수와 행렬 대수학이 총동원됩니다.

*   **2D 픽셀 → 3D 공간 디프로젝션 (Deprojection)**:
    카메라 렌즈의 굴곡과 초점거리(Intrinsics)를 이용해 2D 화면상의 `(X, Y)` 픽셀을 물리적 공간의 `(X, Y, Z)` 빔(Ray)으로 역산하는 `rs2_deproject_pixel_to_point` 공식이 사용됩니다.
*   **RANSAC 기반 강건한 평면 피팅 수학 (Robust Plane Fitting)**:
    YOLO-OBB가 인식한 박스 구역 내부의 모든 깊이 점(Point Cloud)들을 모은 뒤, RANSAC 알고리즘이 무작위 샘플링을 반복하여 수학적 평면 방정식 **$Ax + By + Cz + D = 0$** 을 도출합니다. 
    *   *왜 튀는 값을 무시하는가?* RANSAC은 대다수의 점(Inliers: 소켓 윗면)이 지지하는 모델만 남기고, 소수 의견(Outliers: 바닥면, 노이즈)은 가차 없이 버립니다. 이 덕분에 겹쳐진 소켓의 아래쪽이나 바닥면 픽셀이 박스에 섞여 들어와도 중심점의 깊이가 푹 꺼지지 않습니다.
*   **법선 벡터 역산 (Normal to Euler Angles)**:
    평면 방정식에서 도출된 법선 벡터 수식 **$V = [N_x, N_y, N_z]$** 를 로봇 팔의 관절 꺾임 각도인 **Roll, Pitch**로 변환합니다. `math.atan2` 삼각함수를 활용하여 $X-Z$, $Y-Z$ 축의 회전량을 구함으로써 흡착툴이 정확히 소켓의 기울기에 맞춰 직각(90도)으로 접근(Approach)하게 만듭니다.

### 3. `realsense_config.py` (카메라 하드웨어 제어 및 스킨 필터링)
Intel RealSense D435i 카메라의 스트리밍 설정과 원시 데이터 스킨(Post-Processing Filter)을 담당합니다. 소프트웨어로 넘어가기 전, 하드웨어 칩셋 단에서부터 데이터 품질을 극대화합니다.

*   **재질 맞춤형 튜닝 (VISUAL_PRESET = 3)**:
    소켓이 금속(Metal)이었다면 난반사 필터(High Density)를 썼겠지만, 우리 타겟은 **빛 반사가 적은 플라스틱**입니다. 따라서 모서리 노이즈보다는 표면의 편평도를 살리는 `High Accuracy (고정밀)` 프로파일을 베이스로 사용합니다.
*   **4단계 하드웨어 필터링 구조**:
    1. `Decimation Filter`: 데이터 해상도를 조절해 연산량을 줄입니다.
    2. `Spatial Filter` (공간 필터): 인접한 픽셀들의 높낮이를 분석해 엣지(모서리)를 보존하면서 표면을 다듬어 줍니다. (Edge-Preserving Smoothing)
    3. `Temporal Filter` (시간 필터): 프레임 간의 변화량을 추적해 지글거리는(Jitter) 픽셀을 잠재웁니다.
    4. `Hole Filling Filter`: 검은색으로 깊이가 뚫린 구멍(결측치)에 주변 픽셀의 깊이 값을 덮어씌워 소켓 중간의 오목한 핀(Pin) 구멍들을 강제로 메웁니다. (RANSAC이 평면을 잡기 극도로 편해집니다.)

### 4. `tracker.py` (실시간 안정화 추적 필터)
카메라 노이즈 때문에 점(좌표)이 화면상에서 바들바들 떠는 현상(Jumping)을 억제하는 AI 기반의 물리 필터입니다.

*   **칼만 필터 (Kalman Filter)**: X, Y, Z 위치 좌표 안정화용. 
    로봇이 움직이거나 카메라가 흔들릴 때, 물체의 "과거 이동 속력과 가속도"를 관성의 법칙으로 예측(Predict)하고 카메라 센서 값(Measure)과 합쳐서 잡음을 상쇄시킨 최적의 좌표(Update)를 구해냅니다.
*   **지수 이동 평균 (EMA - Exponential Moving Average)**: Roll, Pitch, Yaw 각도 안정화용.
    각도는 180도와 -180도를 넘나들 수 있기 때문에, 칼만 필터 대신 이전 프레임의 각도들의 꼬리를 잡고 누적 평균(알파 상수=0.2)을 내어 각도가 훅휙 돌아가는 멀미나는 현상을 억제시켰습니다.

### 5. `visualization.py` (2D/3D 화면 UI 렌더링)
보이지 않는 3D 수학의 세계를 인간의 눈으로 디버깅할 수 있도록 화면상에 시각화해 줍니다. 

*   **XZ 평면 단면도 분석기**: 우측 하단의 **Side View** 창은 실제 Z축 깊이를 직관적으로 보여줍니다. 
*   **노란색 기울기 벡터 선**: 방금 `geometry.py`의 RANSAC이 뽑아낸 기울기를 다시 역산해서, 이 XZ 단면도 상에 노란색 대각선으로 나타냅니다. 현장 엔지니어가 화면상에 소켓의 기울어진 모양과 저 노란 선이 똑같이 평행을 이루는지 1초 만에 눈으로 직관적으로 검증할 수 있는 최강의 디버깅 무기입니다.

## 🚀 완벽한 파이프라인 데이터 흐름도 (Data Life Cycle)

로봇이 "저 튀어나온 12핀 소켓을 집자!"고 결심하고 하강하기까지 단 **0.1초** 동안 일어나는 데이터의 여정은 다음과 같습니다.

1.  **Photon to Pixel (광원 → 픽셀)**
    `realsense_config.py`가 D435i 센서에서 튕겨나온 적외선을 4단계 필터로 마사지하여 찌그러짐 없는 RGB 해상도와 뎁스(Depth) 맵을 만들어 냅니다.
2.  **YOLO11-OBB Inference (사물 인식 및 초기 각도 추출)** 
    RGB 이미지가 가장 최신 아키텍처인 YOLO11-OBB 뉴럴넷에 들어갑니다. 모델은 모서리에 여백 없이 소켓 테두리에 꽉 들어맞는 비스듬한 바운딩 박스 `(x_center, y_center, width, height)`와 핵심 각도인 **`Yaw (수평 회전각)`**을 한 방에 토해냅니다.
3.  **Depth Masking & ROI Cropping (심도 마스킹)**
    YOLO가 알려준 영역에 속하는 깊이 점들만 쏙 빼냅니다. OBB 모델을 사용했으므로 바닥면 픽셀(노이즈)은 거의 담기지 않습니다.
4.  **RANSAC Plane Fitting (평면 математи화)**
    추출된 3D 점 구름(Point Cloud)들이 `geometry.py` 로 넘어옵니다. RANSAC 알고리즘이 소켓 안쪽에 파인 동그란 핀(Pin) 구멍 깊이 등 미세한 소수 픽셀(Outliers)들을 과감히 무시해 버리고, 소켓 '윗면 철판'에 딱 맞는 강력한 `[N_x, N_y, N_z]` 법선 평면 벡터를 뽑아냅니다.
5.  **3D Math Conversion (로봇 축 매핑)**
    이 법선 평면 벡터의 한가운데(Center)를 삼각함수를 통해 6차원 벡터 `(X_mm, Y_mm, Z_mm, Roll_deg, Pitch_deg, Yaw_deg)`로 변환합니다. 바로 여기가 흡착툴이 닿을 물리적 위치와 각도입니다.
6.  **IndyDCP Command (로봇 실행)**
    `indy_controller.py`를 통해 로봇 팔이 관절을 우아하게 꺾으며(Roll, Pitch, Yaw 모션 적용) 내려가 해당 표면 각도와 완벽히 90도 십자가를 이룬 상태로 진공을 작동시켜 물체를 깔끔하게 낚아챕니다.

## 🛠️ CLI 구동 모드 가이드 (`binpicking_3d.py`)

메인 파일을 실행할 때 붙이는 매개변수(Flag)에 따라 모드가 3단계 뎁스로 완전히 바뀝니다.

### 모드 1. 실시간 스트리밍 모드 (관찰 및 검증 전용)
로봇은 전혀 연동되지 않는 오프라인 상태입니다. 단순히 트래커(Kalman)가 활성화되어 화면의 UI와 각도들이 실시간으로 얼마나 빠릿하고 부드럽게 따라오는지 60FPS로 육안 검사를 진행합니다.
```bash
python src/detection/binpicking_3d.py
```

### 모드 2. 픽킹 알고리즘 연산 시뮬레이션 (위험성 0%)
마음의 결정을 내리고 로봇이 목표에 접근하기 직전의 **"멀티 프레임 깊이 추출"**과 일회성 **"RANSAC 정밀 계산"** 동작만을 체크합니다. 스페이스바를 누르거나 일정 주기가 돌았을 때 화면이 멈추면서 노란 선(기울기)이 대상에 맵핑되며, 터미널엔 최종 6D Pose 결과값만 출력되고 종료됩니다.
```bash
python src/detection/binpicking_3d.py --pick
```

### 모드 3. 실전 인디(Indy7) 로봇 연동 빈픽킹 모드
시뮬레이션에서 나온 확정된 3D 6D Pose 좌표를 실제 로봇에게 IP 패킷(IndyDCP)으로 전송하여 관절 모터를 기동시킵니다. 흡착 스위치를 가동하고 Z축까지 하강하여 리얼 시나리오 픽킹을 수행하는 프로덕션 모드입니다. (반드시 로봇 주변에 방해물이 없어야 합니다!)
```bash
python src/detection/binpicking_3d.py --pick --robot
```
