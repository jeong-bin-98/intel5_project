# 로봇 빈픽킹(Bin-Picking) 데이터 파이프라인 가이드

본 디렉토리(`src/pipeline`)는 로봇에 달린 깊이 카메라(Intel RealSense D435i)로 전기기능사 12핀 소켓을 촬영하고, 이를 인공지능이 인식할 수 있도록 라벨링 및 학습시키는 **[ YOLO11-OBB 학습 자동화 파이프라인 ]**입니다.

과거 복잡했던 5단계의 노이즈 제거 및 전처리 과정을 최신 AI 도입을 통해 **가장 효율적인 3단계로 압축**하였습니다.

---

## 🧠 핵심 동작 원리 (Why OBB?)

빈픽킹(무작위로 쌓인 물건 집기) 시스템에서 가장 중요한 것은 **"물체가 얼마나 기울어져 있는가(Yaw 각도)"**와 **"바닥면(노이즈)을 배제하고 순수 물체의 깊이만 얻는 것"**입니다.

기존의 수평/수직 사각형 박스(AABB)는 비스듬히 누워있는 소켓을 잡을 때 필연적으로 모서리에 **바닥면 허공 픽셀**이 포함되어 3D 좌표를 왜곡시킵니다.
이를 해결하기 위해 본 파이프라인은 **OBB(Oriented Bounding Box, 회전 바운딩 박스)** 기법을 도입했습니다.

1.  **밀착된 픽셀 추출**: 소켓 모양 그대로 박스가 기울어지게 쳐지므로 바닥면 노이즈가 원천 차단됩니다.
2.  **Yaw 각도 자동 획득**: 딥러닝(YOLO11)이 박스의 크기뿐만 아니라 **'회전 각도'**까지 한 번에 예측하여 출력하므로, 흡착툴(Suction)이 내려가야 할 정확한 자세(Orientation)를 공짜로 얻게 됩니다.

---

## 🚀 파이프라인 사용 방법 (Step-by-Step)

순서대로 아래의 3개 스크립트를 실행하여 로봇 비전 모델을 완성합니다.

### Step 1: 이미지 데이터 수집 (`step1_capture.py`)
카메라를 로봇에 달거나 고정한 상태에서, 소켓을 무작위로 흩뿌려놓고 촬영합니다.
*   **실행**: `python src/pipeline/step1_capture.py`
*   **역할**: RealSense 카메라를 켜고 RGB 이미지와 Depth(깊이) 이미지를 페어로 저장합니다.
*   **팁**: 소켓이 똑바로 누운 것, 뒤집힌 것, 비스듬히 세워진 것 등 다양한 환경에서 **최소 50장 ~ 100장** 정도를 촬영하는 것이 좋습니다.

### Step 2: OBB 라벨링 (두 가지 방식 중 택 1)

촬영된 이미지에 정답지(라벨)를 다는 작업입니다. 라벨링 도구가 두 가지 제공되며, 상황에 맞게 선택하여 사용합니다.

> ⚠️ **주의**: SAM 방식을 사용하려면 `models/` 폴더 내부에 SAM 사전학습 가중치 파일(`sam_vit_b_01ec64.pth`)이 반드시 존재해야 합니다. (다운로드 명령어는 루트 README 참조)

---

#### 방식 A: `step2_sam_labeler.py` — SAM 클릭 자동 윤곽

소켓 중심을 클릭 한 번만 하면 SAM AI가 픽셀 외곽선을 자동으로 추출하고, `minAreaRect`로 OBB를 계산합니다.

```bash
python src/pipeline/step2_sam_labeler.py          # vit_b (빠름, 기본)
python src/pipeline/step2_sam_labeler.py --heavy  # vit_h (정확)
```

*   **장점**: 클릭 한 번으로 라벨 자동 생성, 속도가 빠름
*   **단점**: SAM이 배경과 혼동할 경우 윤곽이 부정확할 수 있음

---

#### 방식 B: `step2_obb_labeler.py` — SAM + 수동 4-코너 혼합

SAM 자동 모드와 수동 4-코너 클릭 모드를 `m` 키로 전환하여 사용합니다. SAM 결과가 좋지 않을 때 수동으로 정밀하게 보완할 수 있습니다.

```bash
python src/pipeline/step2_obb_labeler.py          # vit_b (빠름, 기본)
python src/pipeline/step2_obb_labeler.py --heavy  # vit_h (정확)
```

*   **장점**: SAM + 수동 혼합으로 정밀도 높은 라벨 생성 가능
*   **단점**: 수동 모드에서 코너 4점을 직접 클릭해야 함

**조작키**

| 키 | 동작 |
|----|------|
| 마우스 좌클릭 (SAM 모드) | 소켓 클릭 → 윤곽 자동 탐지 + OBB 계산 |
| 마우스 좌클릭 4번 (수동 모드) | 코너 4점 순서대로 클릭 → OBB 완성 |
| `1` | 현재 박스를 **8pin** (클래스 0)으로 저장 |
| `2` | 현재 박스를 **12pin** (클래스 1)으로 저장 |
| `u` | 마지막 라벨 취소 (undo) |
| `r` | 현재 작업 리셋 |
| `m` | SAM 모드 ↔ 수동 모드 전환 |
| `t` | 현재 이미지 저장 후 다음 이미지 |
| `s` | 현재 이미지 스킵 |
| `q` | 저장 후 종료 |

**결과물**: `dataset/labels/train/` 폴더에 YOLO OBB 포맷(`.txt`)으로 라벨 생성
각 줄 형식: `class x1 y1 x2 y2 x3 y3 x4 y4` (정규화 좌표, 4 코너)

### Step 3: YOLO11-OBB 인공지능 학습 (`step3_train_yolo_obb.py`)
라벨링이 끝나면 드디어 물체를 스스로 찾게 훈련시키는 단계입니다.
*   **실행**: `python src/pipeline/step3_train_yolo_obb.py`
*   **역할**: 최신 초경량 모델인 `yolo11n-obb.pt`를 베이스로 하여 우리의 12핀 소켓을 학습시킵니다. 빈픽킹 환경을 완벽히 정복할 수 있도록 **180도 무작위 회전 데이터 증강(Augmentation)**이 기본으로 켜져 있습니다.
*   **결과물**: 약 10~30분의 학습이 끝나면 `runs/detect/socket_detector_obb/weights/best.pt` 라는 최적의 AI 뇌(가중치 파일)가 탄생합니다.
